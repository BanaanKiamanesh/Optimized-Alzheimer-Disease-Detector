DataSet here is a 1-Channel EEG Data collected from 60 people with mild or severe Alzheimer disease along with helthy people for about 23.6 seconds. The goal is to make a ML Classifier to be able to seperate and identify them.

Data PreProcessing

Reading Data from text files and turning them into .mat files to be able to manipulate them super fast. And the designing a band-stop notch filter for 50Hz powerline noise removal.
% Reading Raw Data
Mild = zeros(20, 4097);
Normal = zeros(20, 4097);
Severe = zeros(20, 4097);
% Read Data From Text
for it = 1:20
if it<10
Mild(it, :) = textread(['RawDataset\mild\F00', num2str(it), '.txt'], '%d');
Normal(it, :) = textread(['RawDataset\normal\N00', num2str(it), '.txt'], '%d');
if it>1
Severe(it, :) = textread(['RawDataset\severe\O00', num2str(it), '.txt'], '%d');
end
else
Mild(it, :) = textread(['RawDataset\mild\F0', num2str(it), '.txt'], '%d');
Normal(it, :) = textread(['RawDataset\normal\N0', num2str(it), '.txt'], '%d');
Severe(it, :) = textread(['RawDataset\severe\O0', num2str(it), '.txt'], '%d');
end
end
% Designing Butterworth Notch Filter for 50Hz Noise Removal
fs = 173.61; % Sampling Freq
wl = 49; % Cuoff LowerBound
wh = 51; % Cuoff UpperBound
order = 3; % Filter Order
type = 'stop'; % Filter Type
[b, a] = butter(order, [wl, wh]/(fs/2), type); % Create Filter
% Apply Filter
for it = 1:size(Mild, 1)
Mild(it, :) = filtfilt( b, a, Mild(it, :));
Normal(it, :) = filtfilt( b, a, Normal(it, :));
Severe(it, :) = filtfilt( b, a, Severe(it, :));
end
% Saving Prepared Data
RawData.Mild = Mild;
RawData.Normal = Normal;
RawData.Severe = Severe;
% Creating and Saving Labels
DataLabels.MildLabels = repmat({'Mild'}, 20, 1);
DataLabels.NormalLabels = repmat({'Normal'}, 20, 1);
DataLabels.SevereLabels = repmat({'Severe'}, 20, 1);
% Saving EEG Sampling Frequency
RawData.Fs = fs;
save RawData RawData
save DataLabels DataLabels
disp("Data Cleared And Saved as a RawData.mat and DataLabels.mat .")
Data Cleared And Saved as a RawData.mat and DataLabels.mat .
clear;

Feature Extraction

This section is responsible for seperating delta, theta, alpha, beta and gamma waves and Extract time and frequency domain features and saving them.

Time Domain

% Load File, Parameter Daclaration & Initialization
load RawData
Fs = RawData.Fs; % Sampling Freq
Mild = RawData.Mild;
Normal = RawData.Normal;
Severe = RawData.Severe;
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Rhythm Filtering %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% Each Column Contain Frequency Bounds of Delta, Theta,
% Alpha, Beta and Gamma Waves Respectively..
bound = [0.1, 4, 8, 12, 30
4, 7, 12, 30, 70];
% Filter Options
type = 'bandpass'; % Filter Type
order = 3; % Filter Order
% Designing Filters, Frequency Seperation and Time Feature Extraction
for it = 1:size(Mild, 1)
for freqIt = 1:size(bound, 2)
% Seperate Rhythms and Perform Feature Selection
[b, a] = butter(order, [bound(:, freqIt)']/(Fs/2), type);
tempMild = filtfilt( b, a, Mild(it, :));
tempNormal = filtfilt( b, a, Normal(it, :));
tempSevere = filtfilt( b, a, Severe(it, :));
tempFMild(freqIt, :) = MyFeatureExtractor(tempMild);
tempFNormal(freqIt, :) = MyFeatureExtractor(tempNormal);
tempFSevere(freqIt, :) = MyFeatureExtractor(tempSevere);
end
TimeFeatures.Mild(it, :) = reshape(tempFMild', 1, size(bound, 2)*8);
TimeFeatures.Normal(it, :) = reshape(tempFNormal', 1, size(bound, 2)*8);
TimeFeatures.Severe(it, :) = reshape(tempFSevere', 1, size(bound, 2)*8);
end
% Save Again
save TimeFeatures TimeFeatures
disp("Time Domain Features Extracted and Saved into TimeFeatures.mat .")

Frequency Domain

% Load File, Parameter Daclaration & Initialization
load RawData
Fs = RawData.Fs; % Sampling Freq
Mild = RawData.Mild;
Normal = RawData.Normal;
Severe = RawData.Severe;
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% Rhythm Filtering %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% Each Column Contain Frequency Bounds of Delta, Theta,
% Alpha, Beta and Gamma Waves Respectively..
bound = [0.1, 4, 8, 12, 30
4, 7, 12, 30, 70];
%% Freq Seperation and Freq Feature Extraction
siglen = size(Mild, 2);
x = linspace(0, Fs/2, ceil(siglen/2));
for it = 1:size(Mild, 1)
fftMild = fft(Mild(it, :));
fftNormal = fft(Normal(it, :));
fftSevere = fft(Severe(it, :));
fftMild = abs(fftMild(1:ceil(siglen/2)));
fftNormal = abs(fftNormal(1:ceil(siglen/2)));
fftSevere = abs(fftSevere(1:ceil(siglen/2)));
% Seperate Rhythms and Perform Feature Selection
for freqIt = 1:size(bound, 2)
index = find(x >= bound(1, freqIt) & x <= bound(2, freqIt));
tempFMild(freqIt, :) = MyFeatureExtractor(fftMild(index));
tempFNormal(freqIt, :) = MyFeatureExtractor(fftNormal(index));
tempFSevere(freqIt, :) = MyFeatureExtractor(fftSevere(index));
end
FrequencyFeatures.Mild(it, :) = reshape(tempFMild', 1, size(bound, 2)*8);
FrequencyFeatures.Normal(it, :) = reshape(tempFNormal', 1, size(bound, 2)*8);
FrequencyFeatures.Severe(it, :) = reshape(tempFSevere', 1, size(bound, 2)*8);
end
% Save Again
save FreqFeatures FrequencyFeatures
disp("Frequency Domain Features Extracted and Saved into FreqFeatures.mat .")
Frequency Domain Features Extracted and Saved into FreqFeatures.mat .
clear;

Main Classification

Here as the final and main section of the code, collective feature selection for the extracted feature are performed with the use of Bio-Geography-Based optimization algorithm. and Classifying with KNN and LDA and Decision Tree.
There are bunch of options that can be selected and changed. Like Mutaion Rate, Feature Num, Classifier type, CostFunction...
There will be Final File saved as 'Soltion.mat'. Which contains the found Solution and the InterClass Accuracy of the Data.
The process is Accelerated Using Parallel Prgramming Toolbox!
% Loading Datas with Labels and Features
